# WORKOUT Sport Center — Методические материалы

Интерактивный сайт с карточками материалов в стиле Яндекса и фирменной палитре логотипа (красный #FF2D2D).

## Запуск

1. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8080
```

2. Откройте http://localhost:8080

## Контент из Word

1. Редактируйте `Документ Microsoft Word.docx` или шаблон `WORKOUT_Методические_материалы.docx`
2. Положите `.mp4` в папку `video/` (название = раздел + упражнение + номер)
3. Обновите сайт:

```bash
python scripts/build-content.py
# или только видео:
python scripts/assign-videos.py
python scripts/apply-vk-videos.py   # только VK из vk-videos.json
```

Ссылки VK хранятся в `data/vk-videos.json` (для GitHub Pages без тяжёлых mp4).

### Сопоставление видео по имени файла

| Фрагмент в названии | Раздел на сайте |
|---------------------|-----------------|
| `ПОДГОТОВИТЕЛЬНЫЙ` | Подготовительный уровень |
| `НАЧАЛЬН` | Начальный уровень |
| `СРЕДН` | Средний уровень |
| `ПРОДВИНУТ` | Продвинутый уровень |
| `РАЗМИНКА И РАЗОГРЕВ ДОП` | Разминка (доп. блок) |
| `РАЗМИНКА И РАЗОГРЕВ` | Разминка и разогрев |
| `РЕКОМЕНДАЦИИ` | Рекомендации по процессу |
| `ПОДТЯГИВАНИЯ` / `ОТЖИМАНИЯ` | Группировка внутри уровня |

3. Пересоздать красивый Word-шаблон:

```bash
python scripts/create-word-template.py
```

## Структура

- `index.html` — главная страница
- `css/main.css` — стили
- `js/main.js` — карточки, переходы, закладки, поиск
- `data/content.json` — данные для сайта
- `logo.jpg` — логотип и брендинг
- `scripts/` — сборка контента из Word

## Возможности

- Сетка карточек как на макете
- Плавное открытие материала с FLIP-переходом
- Фильтры по категориям и поиск
- Закладки (localStorage)
- Локальные видео из папки `video/` (автопривязка по названию файла)
